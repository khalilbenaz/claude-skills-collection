# Career Transition Planner

## Étape 1 — Bilan de situation actuelle

Commence toujours par une grille de lecture rapide :

| Axe              | Questions clés                                                 |
|------------------|----------------------------------------------------------------|
| Satisfaction     | Qu'est-ce qui t'énerve le lundi matin ? Qu'est-ce qui te donne de l'énergie ? |
| Compétences      | Quelles compétences pourrais-tu utiliser dans un autre contexte ? |
| Valeurs          | Autonomie, impact, sécurité, créativité, management, technique ? |
| Contraintes      | Mobilité géographique, salaire plancher, charge familiale ?     |

**Output attendu :** une liste de 3-5 compétences transférables et 2-3 valeurs non négociables.

---

## Étape 2 — Exploration des options

### Critères de décision pour shortlister des métiers cibles

1. **Chevauchement compétences** ≥ 60 % → transition rapide (<12 mois)
2. **Chevauchement** 30-60 % → requalification partielle (12-24 mois, bootcamp ou formation courte)
3. **Chevauchement** < 30 % → reconversion profonde (>24 mois, diplôme ou alternance)

### Passerelles courantes par profil

| Profil actuel         | Pivots courants (2026)                                         |
|-----------------------|----------------------------------------------------------------|
| Dev backend           | AI/ML Engineer, Platform Engineer, Tech Lead, Solution Architect |
| Dev frontend          | Product Designer, Developer Advocate, Technical PM            |
| Consultant IT         | Product Manager, Freelance Coach, Directeur de projets         |
| Ingénieur industriel  | DevOps/SRE, Data Engineer, Lean Coach                         |
| Commercial B2B        | Account Executive SaaS, Sales Engineer, Customer Success       |
| RH / Recruteur        | People Ops, RevOps, Learning & Development Manager             |

### Validation de l'hypothèse cible

Avant de s'engager, valider avec au moins **2 sur 3** :
- [ ] Entretien informationnel avec quelqu'un du métier cible (≥ 30 min)
- [ ] Stage / mission freelance courte (<1 mois) ou projet perso publié
- [ ] Offres d'emploi sur le marché local cohérentes avec le profil visé

## Étape 3 — Plan d'action en phases

### Phase 1 — Exploration (semaines 1-6)
```
Actions concrètes :
- Contacter 5 personnes sur LinkedIn dans le métier cible (message court, 3 lignes max)
- Lire 2-3 rapports sectoriels récents (ex. State of AI Jobs 2026, LinkedIn Jobs Report)
- Lister 10 offres d'emploi cibles → extraire les compétences récurrentes
- Identifier 1 formation ou certification courte (Coursera, RNCP, bootcamp)
```

### Phase 2 — Montée en compétences (mois 2-6)
```
Actions concrètes :
- Choisir une formation ciblée (critère : durée ≤6 mois, ROI prouvé, reconnu marché)
- Lancer 1 side project public (GitHub, portfolio, newsletter, mission micro-freelance)
- Construire/refaire le CV et le profil LinkedIn pour le nouveau métier
- Identifier 3 entreprises cibles (culture, taille, secteur alignés avec valeurs)
```

### Phase 3 — Transition active (mois 6-12)
```
Actions concrètes :
- Candidatures ciblées (qualité > quantité, 10-20 candidatures max)
- Activer le réseau : anciens collègues, alumni, communautés Slack/Discord du secteur
- Préparer 3 histoires STAR pour les compétences transférables clés
- Négocier salaire en tenant compte de la courbe d'apprentissage (attente réaliste : -10/20 % initial)
```

## Étape 4 — Analyse de risque financier

**Calcul minimal avant de sauter :**
```
Runway = Épargne disponible / Dépenses mensuelles fixes
→ Runway ≥ 6 mois : transition sereine
→ Runway 3-6 mois : transition possible avec revenus d'appoint (freelance, temps partiel)
→ Runway < 3 mois : préparation nécessaire avant de quitter le poste actuel
```

**Sources de financement à explorer (France 2026) :**
- CPF (Compte Personnel de Formation) — budget disponible sur moncompteformation.gouv.fr
- Projet de Transition Professionnelle (PTP / ancien CIF) — maintien de salaire jusqu'à 2 ans
- Aide à la reconversion Pôle Emploi / France Travail si démission légitime
- OPCO de la branche actuelle pour formations en alternance

## Étape 5 — Timeline réaliste

```
Semaines 1-2   : Bilan + shortlist de 2-3 métiers cibles
Semaines 3-6   : Validation par entretiens informationnels
Mois 2-3       : Formation ou side project lancé
Mois 4-6       : CV/LinkedIn refait, premières candidatures exploratoires
Mois 6-9       : Candidatures actives + entretiens
Mois 9-12      : Offre acceptée ou ajustement de cap
```

---

## Anti-patterns et pièges courants

- **Quitter sans filet** : démission impulsive sans runway ni cible claire → éviter.
- **Over-formation** : accumuler des certifications sans side project ni réseau → signal faible pour les recruteurs.
- **Métier fantasmé** : choisir un métier sur l'image (dev, designer, PM) sans validation terrain → toujours faire au moins 1 entretien informationnel avant de s'engager.
- **Comparaison salariale brute** : comparer son salaire actuel (senior) au salaire d'entrée dans le nouveau domaine → intégrer la courbe de progression à 2-3 ans.
- **Réseau négligé** : envoyer uniquement des candidatures à froid → 60-70 % des postes se pourvoient via le réseau.
- **Attendre d'être "prêt"** : la transition parfaite n'existe pas — commencer par un petit pas (entretien informationnel, side project) est toujours mieux que d'attendre.

---

## Bonnes pratiques 2026

- Les recruteurs vérifient GitHub, LinkedIn et portfolio **avant** le CV.
- Les transitions réussies combinent toujours 3 éléments : preuve (projet/mission), réseau (référence), récit (comment tu racontes le changement).
- Les bootcamps intensifs (3-6 mois) ont remplacé les masters 2 ans pour la plupart des pivots tech.
- L'IA augmente la demande en profils hybrides (tech + domaine métier) — valoriser sa double compétence plutôt que de l'effacer.
