# Packing Checklist — Guide opérationnel

## Étape 1 — Collecter le contexte (obligatoire avant de générer)

Pose ces 5 questions si elles ne sont pas déjà précisées :

| Info | Exemples / options |
|---|---|
| **Destination** | Pays, zone climatique (tropical, alpin, désert, Europe tempérée) |
| **Durée** | Nombre de nuits (< 3 nuits = bagage cabine possible) |
| **Saison / Météo** | Températures min/max attendues, risque de pluie |
| **Type de voyage** | Affaires, aventure/trek, plage, ville culturelle, road-trip |
| **Transport** | Avion low-cost / compagnie régulière / train / voiture (règles bagages) |

**Règle de décision bagages :**
- Avion low-cost + ≤ 4 nuits → viser bagage cabine (max 10 kg / 55×40×20 cm selon Ryanair/easyJet)
- Avion régulier soute → 23 kg en général, liquides ≤ 100 ml en cabine
- Train ou voiture → pas de limite stricte, mais poids = confort

## Étape 2 — Génération de la checklist personnalisée

Génère les sections ci-dessous en **cochant uniquement ce qui s'applique** au profil. Marque `⚠️` les items critiques (oubli = voyage compromis).

### 2.1 Documents & Argent ⚠️

- [ ] ⚠️ Passeport (validité ≥ 6 mois après retour pour la plupart des pays hors Schengen)
- [ ] ⚠️ Visa papier ou QR code e-visa (si requis — vérifier sur iatatravelcentre.com)
- [ ] ⚠️ Carte de crédit internationale (Visa/Mastercard) + une de secours
- [ ] Espèces locales pour arrivée (aéroport, taxi, pourboires)
- [ ] Assurance voyage (numéro d'urgence accessible hors ligne)
- [ ] Billets transport (PDF offline ou screenshots)
- [ ] Réservations hôtel / hébergement (même chose)
- [ ] Carte d'identité (destinations UE si passeport non obligatoire)
- [ ] Permis de conduire international (si location de véhicule)
- [ ] Photocopies séparées de tous les documents + scan en cloud

### 2.2 Vêtements (règle du capsule wardrobe)

Formule de base : `(nb_nuits / 2) + 1` hauts + `nb_nuits / 3` bas (arrondi au-dessus).

| Conditions | Items à ajouter |
|---|---|
| Températures < 10 °C | Manteau technique, sous-couche thermique, bonnet, gants |
| Pluie probable | Coupe-vent imperméable (membrane Gore-Tex ou similaire) |
| > 30 °C | Vêtements respirants (lin, merino), chapeau large bord |
| Plage | Maillot(s), paréo, sandales eau |
| Affaires | Tenue formelle, chaussures de ville (planifier la place dans la valise) |
| Trek / Randonnée | Chaussures montantes imperméables, chaussettes merino, bâtons |
| Soirées / Restaurants chics | Une tenue habillée polyvalente |

- [ ] Sous-vêtements (1 par jour + 1 de secours ; laine merino = séchage rapide)
- [ ] Pyjama léger ou t-shirt nuit
- [ ] Chaussures de marche + tongs ou claquettes
- [ ] Ceinture / ceinture de voyage cachée (zones à risque)

### 2.3 Hygiène & Santé

**Règle cabine :** tous les liquides ≤ 100 ml dans un sac ZIP 20×20 cm (max 1 L total).

- [ ] ⚠️ Médicaments sur ordonnance (quantité + ordonnance + lettre médicale en anglais si pays strict)
- [ ] Trousse de premiers secours : antidouleur, antidiarrhéique, antihistaminique, désinfectant
- [ ] Crème solaire indice adapté (SPF 50 si tropical)
- [ ] Répulsif anti-moustiques (DEET ≥ 30 % pour zones à dengue/paludisme)
- [ ] Shampooing/après-shampooing solide (pas de limite liquide, gain de poids)
- [ ] Brosse à dents + dentifrice voyage
- [ ] Déodorant solide ou stick (< 100 ml si gel)
- [ ] Lentilles + liquide + lunettes de rechange (si porteur)
- [ ] Contraceptifs / protections si besoin
- [ ] Masques chirurgicaux (certains pays encore requis ou utiles avion)

### 2.4 Tech & Accessoires

- [ ] ⚠️ Adaptateur secteur universel (ou adaptateur spécifique pays — ex. UK Type G, US Type A)
- [ ] Chargeur téléphone + câble USB-C/Lightning
- [ ] Powerbank ≤ 100 Wh (max cabine IATA) — vérifier Wh = mAh × V / 1000
- [ ] Écouteurs / casque antibruit (avion long-courrier)
- [ ] Appareil photo ou gimbal si besoin
- [ ] Cadenas TSA (si valise avec serrure, destinations USA)
- [ ] VPN configuré (streaming, accès email professionnel en déplacement)
- [ ] Carte SIM locale ou eSIM préchargée (ex. Airalo pour eSIM internationale)
- [ ] Téléphone configuré en mode avion + wifi avant départ (activation roaming si nécessaire)

### 2.5 Spécifique au type de voyage

**Affaires :**
- [ ] Ordinateur portable + souris + câble HDMI/adaptateur pour présentation
- [ ] Cartes de visite
- [ ] Veste / costume en poche (tissu anti-froissé)

**Aventure / Trek :**
- [ ] Sac à dos 30–50 L (ceinture portage + back system)
- [ ] Lampe frontale + piles de rechange
- [ ] Couverture de survie, sifflet
- [ ] Filtre à eau (Sawyer Squeeze ou pastilles Micropur)
- [ ] Carte papier + boussole (zones sans réseau)

**Plage / Détente :**
- [ ] Crème solaire waterproof + après-soleil
- [ ] Lunettes de soleil (protection UV400)
- [ ] Livre / liseuse (mode avion)
- [ ] Sac étanche (dry bag) pour plages avec snorkeling

**Road-trip :**
- [ ] Brassard pour téléphone au volant + câble de charge voiture
- [ ] Oreiller de voyage gonflable
- [ ] Snacks de route

## Étape 3 — Optimisation & vérifications finales

### Poids et volume : checklist rapide

```
Peser valise vide → ajouter objets → vérifier sur balance (cible : < 7 kg cabine / < 20 kg soute)
Organiser par couches : lourd au fond (chaussures), vêtements roulés au milieu, fragile en haut
Utiliser cubes de rangement (packing cubes) : 1 cube = 1 catégorie
```

### 3 jours avant le départ

- [ ] Vérifier validité documents (passeport, visa, assurance)
- [ ] Télécharger les billets et réservations offline (Google Wallet, Apple Wallet ou PDF)
- [ ] Charger powerbank, téléphone, appareils
- [ ] Vérifier météo destination à J-3 (ajuster vêtements)
- [ ] Informer banque du voyage (éviter blocage carte à l'étranger)

### La veille

- [ ] Valise fermée et pesée
- [ ] Documents rassemblés au même endroit (sac à main / bagage cabine)
- [ ] Réveil programmé (+ 2 heures avant départ recommandé pour vols internationaux)

## Anti-patterns / Pièges fréquents

| Piège | Solution |
|---|---|
| Sur-emballer "au cas où" | Règle : si tu hésites 30 secondes → tu le laisses |
| Liquides > 100 ml en cabine | Cosmétiques solides ou transfert en flacons rechargeables |
| Valise trop lourde retour (achats) | Prévoir espace ou envisager envoi colis depuis destination |
| Powerbank > 100 Wh confisqué | Vérifier Wh : ex. 20 000 mAh × 3,7 V / 1 000 = 74 Wh ✅ |
| Documents uniquement sur téléphone | Toujours une copie papier + scan cloud (Google Drive, iCloud) |
| Médicaments en soute (vol > 8 h) | Médicaments essentiels toujours en bagage cabine |
| Adaptateur oublié | Acheter au départ ou noter le type de prise (TypeC=Inde, TypeG=UK…) |
| Carte bancaire bloquée à l'étranger | Prévenir la banque + avoir 2 cartes de réseaux différents |

## Bonnes pratiques 2026

- **eSIM** : activer via Airalo, Holafly ou opérateur local avant départ ; moins cher que le roaming, dispo en 2 minutes.
- **Vêtements merino** : séchage rapide (12–24 h), pas d'odeur, polyvalent chaud/froid ; rentabilise sur voyages > 5 jours.
- **Packing cubes compressibles** : réduction de volume ~30 %, tri facilité à l'hôtel.
- **Assurance voyage avec annulation** : obligatoire si billet > 500 €, couvre rapatriement et frais médicaux.
- **Checklist numérique partagée** : utiliser Google Keep, Notion ou AnyList pour cocher en temps réel et partager avec un accompagnant.
