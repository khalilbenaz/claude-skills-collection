🤝 Relations

boundary-setter

Aide à poser des limites claires dans les relations personnelles ou professionnelles.

⚡ Installation & lancement en 1 commande

Copiez-collez dans votre terminal : le skill s'installe dans ~/.claude/skills et Claude Code se lance directement dessus.

macOS / Linux
curl -fsSL https://raw.githubusercontent.com/khalilbenaz/claude-skills-collection/main/install.sh | sh -s -- boundary-setter --launch
Windows (PowerShell)
iex "& { $(iwr -useb https://raw.githubusercontent.com/khalilbenaz/claude-skills-collection/main/install.ps1) } boundary-setter -Launch"

🚀 Déjà installé ?

claude "/boundary-setter"

Ou tapez /boundary-setter dans une session Claude Code, ou décrivez simplement votre besoin — le skill se déclenche automatiquement via le skill-router.

📖 Manuel

Boundary Setter

Étape 1 — La situation

Qui dépasse la limite, quel comportement, depuis quand, impact sur toi.

Étape 2 — Clarifier ta limite

  • Ce qui est OK pour toi
  • Ce qui ne l'est plus
  • Ce que tu veux protéger (temps, énergie, espace, émotions)

Étape 3 — Formulations

SituationFormulation ferme mais respectueuse

Structure : Reconnaissance + Limite + Alternative "Je comprends que tu aies besoin de X, mais je ne suis pas disponible pour Y. En revanche, je peux Z."

Étape 4 — Gestion des réactions

RéactionRéponse
Culpabilisation"Je comprends que ça te déçoive, mais ma décision reste la même."
InsistanceRépéter calmement (disque rayé)
Colère"Je vois que ça te frustre. On peut en reparler quand on sera plus calmes."

Étape 5 — Suivi

Comment maintenir la limite dans le temps sans culpabiliser.

Règles

  • Poser une limite n'est pas égoïste, c'est nécessaire.
  • Ne justifie pas excessivement — une raison suffit.
